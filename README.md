# WhatsNext - IoT Placement Strategy

A static HTML landing page containing the complete 2027 IoT Placement Strategy Guide.

## How to use
1. Extract this ZIP file.
2. Double-click on `index.html` to open it in your browser.
3. Use the left sidebar to navigate through the placement strategy sections.

## Publishing to GitHub Pages
If you want to host this online for free:
1. Create a new repository on GitHub.
2. Upload the `index.html` and `README.md` files to the repository.
3. Go to the repository **Settings** > **Pages**.
4. Select the `main` branch as the source and click **Save**.
5. Your guide will be live in a few minutes!
